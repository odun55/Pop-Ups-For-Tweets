Pop-Ups for Tweets

An independent extension that opens X posts and replies in a compact Chrome window. It is not affiliated with or endorsed by X.

Right-click a post and choose Open in popup. On Windows, Ctrl + right-click opens it directly.

Privacy policy

Last updated: October 24, 2026.

On x.com and twitter.com, the extension reads the URL of the post you right-click so it can open that post in a small Chrome window. The extension does not collect post text, replies, passwords, cookies, or account details.

For the regular context menu, the selected post URL may remain in Chrome's temporary storage.session memory until you choose the menu item or right-click another post in the same tab. It is removed when the menu item is used. Otherwise, session storage is cleared when the browser restarts or the extension is reloaded, updated, or disabled. The active window ID is also stored temporarily and removed when that window closes.

No data is sent to the extension developer. There is no advertising, analytics, tracking, or remotely hosted code. When you open a post, Chrome visits X directly; X's own privacy practices apply to its page. The extension does not sell or use the selected URL for another purpose.

Privacy questions: GitHub Issues.
