# Pop-Ups for Tweets

A Manifest V3 Chrome extension that opens an X post and its replies in a compact window beside the main browser window. It is not affiliated with or endorsed by X.

## How it works

1. On `x.com` or `twitter.com`, right-click a post and choose **Open in popup**. On Windows, **Ctrl + right-click** opens it directly.
2. The post and its replies appear in a compact window using X's own page.
3. Press **Esc** or click the main Chrome window to close the popup.

Regular clicks are unaffected. The extension only handles the selected post URL to open the window.
